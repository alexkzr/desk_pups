# Таксон / Desk Pups

Настольные таксы для Windows 10/11 на Python и PySide6. Собственная векторная отрисовка, без чужих изображений.

## Использование

Запустите `Takson.exe`. Такса гуляет у нижнего края рабочей области. Перетащите её к верхней границе обычного окна и отпустите: она сядет на окно. На границу можно упасть сверху. При закрытии, сворачивании или перекрытии окна пёс падает на следующую поверхность. Развёрнутые окна не служат полкой.

Правая кнопка по таксе или значку в трее открывает меню: добавить таксу (до 10), покормить, уложить спать, убрать за собаками, настроить голод, выйти. Экскременты убираются кликом и автоматически через минуту.

## Внешность и движение

Новая такса получает случайное сочетание из четырёх моделей (мультяшная, плюшевая, рисованная, лаконичная), трёх окрасов (рыжая, чёрно-подпалая, мраморная) и двух типов шерсти (гладкая, длинная): 24 сочетания. У мраморных индивидуальный рисунок пятен. Все параметры и рисунок сохраняются; у собак из прежних версий внешность назначается при первом запуске новой версии.

ПКМ по конкретной собаке → «Внешность…» позволяет независимо менять модель, окрас и шерсть. Кнопка «Отмена» сохраняет прежний вид. Уши покачиваются с инерцией, при беге отлетают назад; у длинношёрстных есть очёсы на ушах, животе, лапах и хвосте.

Бодрая сытая такса иногда устраивает zoomies — быстрый бег с разворотами длительностью 5–9 секунд. Проверка возникает через случайные интервалы 90–180 секунд, если энергии хотя бы 55%, голод ниже 45%, а ширина поверхности от 420 пикселей. Сон, еда и туалет не прерываются. ПКМ → «Устроить zoomies!» запускает бег вручную при тех же условиях.

Голод растёт в течение 10 минут от 0 до 100%; с 45% такса просит есть, при 70% сама достаёт миску и ест 5 секунд. Интервал задаётся в настройках (1–120 минут). Миска всегда перед мордой и стоит на одной поверхности с лапами. Через 45–90 секунд после еды — туалет.

В покое такса чередует четыре сидячие позы с паузами 4–7 секунд и плавными переходами: боком, расслабленно с выставленной лапкой, вполоборота и с наклоном головы.

При усталости или по команде появляется лежанка, такса сворачивается калачиком и спит 20 минут. Полная энергия, голод и отложенный туалет сон не прерывают. Голод во сне растёт примерно в 8 раз медленнее. Короткий клик пробуждает: собака разворачивается, потягивается и выходит; затем лежанка исчезает. Перетаскивание проснувшейся собаки начинается после небольшого движения мыши с зажатой кнопкой, лежанка при этом убирается сразу. Команда «Покормить» во сне сначала пробуждает собаку, затем она ест.

Состояние и остаток сна сохраняются каждые 30 секунд и при выходе в `%LOCALAPPDATA%\Takson\state.json`; время при закрытом приложении не учитывается.

## Разработка и сборка

Нужен Python 3.12 x64 на Windows:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Сборка одним файлом: `powershell -ExecutionPolicy Bypass -File build.ps1`. Результат: `dist\Takson.exe`, Python на компьютере пользователя не нужен. Исходники PySide6 распространяются по LGPL/GPL/коммерческой лицензии; при распространении сборок соблюдайте применимые условия Qt/PySide6.

Быстрая проверка запуска: `python main.py --smoke-test` (выходит автоматически). Смешанный DPI и нестандартные окна требуют ручной проверки; приложение использует EnumWindows и DWM для поиска поверхностей.
